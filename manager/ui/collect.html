Proteus fingerprint collector

What this page does

It reads how this device's browser describes itself to any website, so that a Proteus profile can present itself as the same kind of device. Nothing leaves this page unless you press a button below.

Collected: browser and system name and version, device model (phones), screen size and pixel ratio, processor count, memory class, graphics card name and its limits, installed font names from a fixed list, speech voices, touch support.

Not collected: IP address, location, language, time zone, cookies, history, accounts, or anything typed or stored in this browser.

What was read

On another device: download or copy the result, bring it to the computer running Proteus, and use “Import fingerprint” there.
