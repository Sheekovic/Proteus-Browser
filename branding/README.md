# Proteus branding

Proteus is the sea god of Greek myth who changes shape at will. The mark is the
letter P whose bowl curls over like a breaking wave, on the colours of deep and
shallow water.

| File | Use |
| --- | --- |
| `proteus-icon.svg` | The icon. Source for everything below. |
| `icon-16.png` … `icon-512.png` | The icon at fixed sizes. |
| `proteus.ico` | Windows icon (16 to 256 pixels). |
| `proteus-logo.svg`, `proteus-logo-dark.svg` | Icon and name, for light and for dark backgrounds. The letters are drawn as shapes, so no font is needed. |
| `proteus-logo.png`, `proteus-logo-dark.png` | The same, as images (1180 × 300). |
| `social-preview.svg`, `social-preview.png` | Link preview image (1280 × 640), for the repository's social preview setting. |

Colours: `#0b2559` deep, `#1857c9` blue, `#22c1c9` shallow; text `#0f1f3d`.
